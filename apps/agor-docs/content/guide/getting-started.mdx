# Getting Started

Install Agor, open the UI, and follow the onboarding wizard. Your **first AI teammate** will help you get your bearings and get everything else set up. (New here? [Raising Your First AI Teammate](/guide/first-teammate) explains why one teammate is the whole onboarding.)

## Install

<InstallTabs />

Run `agor init` after installation. It shows a multi-select for every supported agentic tool and
requires an intentional selection of at least one. The prompt explains that each selection adds
download time and disk use; credentials are configured later in the UI. Init writes the selection
once to `agentic_tools.installed` and installs the exact version-aligned packages before reporting
success. Press Ctrl+C to cancel. An intentionally tool-free headless deployment must use
`--agentic-tools none`.

To change the deployment policy later, edit `agentic_tools.installed` in `config.yaml`, run
`agor install --sync`, and restart the daemon. Agor does not silently rewrite existing config.
Repeat the readiness check with `agor doctor`; see
[Agentic tools](/guide/extended-install#agentic-tools) for the complete model.

## Follow the onboarding wizard

The first time you open the UI, the **Onboarding Wizard** runs — five quick steps that end with your first AI teammate ready to work:

1. **Goals.** Pick up to two outcomes, such as _Ship without the busywork_ or _Dig into anything_. The recommendations and your teammate's first briefing are tailored to what you want done. You can skip this step for a neutral start.
2. **AI.** Connect a model: Claude (recommended), GPT, Gemini, or a custom endpoint. Paste an API key, use a Claude subscription token, or sign in with ChatGPT; Agor verifies the credential on the spot.
3. **Workspace.** Name your AI teammate and pick its emoji. Agor creates a board named after it — the teammate's home for every branch and session it works on.
4. **Tools.** Review goal-tailored integration suggestions such as Slack, GitHub, Sentry, HubSpot, Linear, or Figma. An admin can connect them from **Marketplace**; other members can ask a workspace admin. This step recommends tools but does not connect them automatically.
5. **You're ready.** Agor seeds the teammate from the [framework repo](https://github.com/preset-io/agor-teammate) onto your board. If you connected an AI model, it also launches the teammate's first session.

Goals and AI are optional. Workspace and Tools are required so onboarding always finishes with a board and an explicit review of the recommendations.

When the board opens, a connected teammate's first session picks up where the wizard left off — it already knows its name, the goals you selected, and which tools were recommended. From there it can register repos, organize its board, structure a workflow, or just be a thinking partner. **Anything a user can do in Agor, the teammate can do too.** It has full access to the [Agor MCP Server](/guide/internal-mcp). If you skipped AI setup, connect a model later from **Settings → AI & Agents** and start a session from the board.

## Customize your install

Agor runs out of the box on SQLite as a single-user instance, but it's designed to scale up:

- **PostgreSQL backend** instead of SQLite, for multi-user / team setups
- **Multiplayer mode** with branch-level [RBAC](/guide/multiplayer-unix-isolation) and per-user permissions
- **Execution isolation** with fail-closed local sandboxing or a reviewed delegated substrate
- **Docker Compose** and source builds for contributor / dev workflows — see the **Docker Compose** tab above for the evaluation quickstart
- **Custom config / database paths** for non-default install layouts

For any of those, see [Extended Installation](/guide/extended-install). For credential alternatives (`claude setup-token`, `codex login --device-auth`, workspace-wide env vars), see [Authentication](/guide/extended-install#authentication).
